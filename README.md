## 폴더
| 경로 | 내용 | 주 담당 |
|------|------|---------|
| `data/` | 로컬 데이터 (CSV는 gitignore) | 데이터 |
| `src/` | 다운로드·전처리·학습 스크립트 | 데이터·모델·자동화 |
| `notebooks/` | EDA·실험 노트북 | 모델·데이터 |
| `figures/` | 논문/보고서용 그림 | 모델·문서 |
| `results/` | 비교표·요약 CSV | 모델 |
| `logs/` | 실험 실행 로그(선택) | 자동화 |
| `docs/` | 중간·최종 보고서 초안 | 문서 |

## Git (요약)
- `main` = 항상 합쳐진 최신본
- 브랜치 = **작업 단위** (`feat/…`, `fix/…`, `docs/…`) → PR → 합친 뒤 삭제
- 역할별 장기 브랜치(`data`, `model` …)는 쓰지 않는다

자세한 규칙은 `TEAM.md`.
