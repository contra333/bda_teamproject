# bda_teamproject

빅데이터분석및이론(AMA8039) 팀 프로젝트 저장소.

- **연구 주제: 미정** — 문제 정의서가 팀에서 확정되면 여기에 한 줄로 적는다.
- **팀 규약: [`TEAM.md`](TEAM.md)** — 처음 온 사람은 이것만 읽으면 된다.
- **회의 · 할 일 · 실험 로그: Notion** (링크는 `TEAM.md`)

## 폴더

| 경로 | 내용 |
|------|------|
| `data/` | 로컬 데이터. 원본 파일은 올리지 않고, 받는 방법만 `data/README.md`에 적는다 |

| `docs/` | 보고서·발표 자료 초안 |
