## 발표 핵심

- 최소 기준선 macro-F1 **0.427**, 댓글만 쓴 TF-IDF + Logistic Regression **0.647**.
- 기본 임계값에서 TF-IDF는 맥락 추가 후 **0.633**. 임계값 조정 후에는 댓글만 **0.644**, 맥락+댓글 **0.662**.
- KcELECTRA fine-tuning은 **0.672 → 0.809**, KLUE-RoBERTa는 **0.637 → 0.778**. 제공된 단일 seed, 5-fold 결과다.
- TF-IDF 맥락 조건의 혐오 Recall은 **0.303 → 0.535**. 같은 조정을 받은 댓글만 조건은 **0.588**이므로, 조정 후 조건 간 차이는 **−0.053**이다.
- 핵심 미해결 질문: PLM의 향상이 맥락·댓글 관계 활용인지, 데이터의 다른 단서 때문인지 아직 구분하지 못했다.

## 원문과 구분한 해석 보완

팀 중간보고서 원문은 수정하지 않았다. 아래는 발표·후속 검토 때 쓸 보완 사항이다.

1. **0.730의 적용 범위:** 같은 댓글에는 같은 라벨을 주는 결정론적 규칙, 현재 5개 test fold의 macro-F1 평균에 대한 사후 상한이다. 정확한 최적화 값은 0.729991로, 기존 계산 0.729798과 모두 세 자리에서 0.730이다. 이를 넘었다고 맥락 이해가 입증되는 것은 아니다. PLM Context-only 통제가 필요하다.
2. **p값의 한계:** 5-fold 학습 데이터가 겹치므로 다섯 개 차이를 독립 반복처럼 다루는 대응 t-검정은 불확실성을 작게 평가할 수 있다. 팀이 정한 기준은 유지하되 p값은 탐색적 근거로 설명한다. [Bengio & Grandvalet, 2004](https://www.jmlr.org/papers/v5/grandvalet04a.html).
3. **비교 규칙:** 조정한 TF-IDF와 미조정 PLM의 차이를 공정한 최종 비교라고 부르지 않는다. 본 비교 그림은 양쪽의 기본 판정 규칙으로 맞췄다.
4. **PR-AUC 표기:** 제공 코드의 `pr_auc`는 `average_precision_score`로 계산한 AP다. 발표에서는 ‘AP(원표의 PR-AUC)’로 설명한다.
5. **학습 시간:** PLM은 Apple MPS 결과다. Colab T4에서 확인한 값이라고 말하지 않는다.
6. **170행:** 확장 베이스라인 50 + 임계값 비교 60 + PLM 60행이다. 고정 임계값 결과가 일부 중복되므로 서로 다른 학습 170회를 뜻하지 않는다.
